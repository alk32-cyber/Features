What's included

Designed for your offer, then built to hold up.

01

Layout and typography that carry meaning

A type scale and grid chosen for your content, so the eye lands on the thing you most need it to land on. Hierarchy does the persuading, not decoration.

02

Motion with a job

Sequencing that helps people read in order, hover and press feedback that confirms what is interactive, and every effect honouring a visitor’s reduced-motion setting.

03

Performance as a design constraint

Images sized and lazy-loaded, fonts subset and self-hosted, scripts kept small and deferred. Fast is not a phase at the end; it decides what the design can be.

04

One obvious path

The promise, the proof, the action, and a fallback in the navigation. Everything else on the page supports that path rather than competing with it.

05

Custom functionality

Calculators, booking flows, filtered galleries, gated resources — the things a plugin does badly and a bespoke build does properly.

06

Built to extend

Structured so a chatbot, a receptionist handover or an automation can be added later without a rebuild.

What it deliberately doesn't do

  • We don’t ship a template with your logo on it. If a template is genuinely the right answer for your budget, we’ll say so.
  • We don’t promise a launch date before scoping. Custom functionality is where estimates go wrong, so we scope that first.
  • We don’t hand over a site nobody can edit. You get something you can update, or we keep maintaining it — your choice, agreed up front.
  • We don’t pad a site with pages that exist only for search engines.

Questions

The things people ask before saying yes.

Do I own the site?

Yes. The code and the content are yours. We will not hold a site hostage to a retainer.

Can I edit it myself?

That depends what you want to edit. Text and images, yes. Reworking a page layout is design work, and pretending otherwise is how sites slowly fall apart.

How is this different from a website builder?

A builder gives you a category’s worth of layouts and stops where they stop. A custom build starts from what you sell and can do things the builder cannot — which only matters if you need those things.

What about hosting?

It is a static-first build, so it runs on any modern host cheaply and fast. We will recommend one and set it up, or deploy to yours.
